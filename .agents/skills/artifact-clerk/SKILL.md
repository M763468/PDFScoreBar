# artifact-clerk

## Purpose
Collect all evidence generated by various skills and tools in the `artifacts/` directory and create a consolidated summary. This is ideal for generating progress reports or verifying that all required verification steps have produced data.

## Output (respond in Japanese)
- Consolidated summary of artifact contents and metadata.
- **Artifact**: `artifacts/evidence_summary.txt`

## Steps

Run commands from the repository root.
1) Run `bash .agents/skills/artifact-clerk/run.sh` to scan the `artifacts/` directory.
2) Read `artifacts/evidence_summary.txt` to see the summary of recent activities and results.
3) Use this summary to report progress to the user or to verify task completion.

## Required commands/permissions
- `bash .agents/skills/artifact-clerk/run.sh`: script to scan and summarize artifacts into `artifacts/`

## Example commands
- `bash .agents/skills/artifact-clerk/run.sh`
