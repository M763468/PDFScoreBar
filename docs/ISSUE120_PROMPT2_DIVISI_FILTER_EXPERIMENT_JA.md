# Issue 120 Prompt 2: Divisi / System-Spanning FP フィルタ検証実験レポート

## 1. 実験の目的
Prompt 2 の調査により、`fp_divisi_spanning` カテゴリの大部分が `probe_seeds` (Pass 1) の `row_stats` クラスタリングによって生成された「巨大な偽の五線バンド（複数段を跨ぐバンド）」に由来し、現在の `staff_vov_threshold: 0.0` の設定によって最終結果まで生き残っていることが判明しました。

本実験の目的は、Prompt 1 で提案された「局所的な五線領域（local staff bands）との垂直オーバーラップ率（`local_staff_overlap`）」によるフィルタリングを適用することで、これらの段跨ぎ FP を効果的かつ安全に除外できるかを検証することです。

## 2. フィルタリングの前提と判定ルール

### 判定の前提
ユーザーとの協議の結果、**「段間の空間に引かれている線（divisiを示す線であっても）は、今回の小節線カウントの目的においては GT として登録されておらず、保護すべき対象ではない」**という前提が確認されました。
そのため、上下の端からの距離などを計算して真の divisi を救済するような複雑なルールは不要であり、単一のシンプルなオーバーラップ率のみで判定を行います。

### 判定ルール
*   **Rule:** 候補の bounding box に対して局所的な五線領域（local staff bands）を取得し、それらとの最大垂直オーバーラップ率 (`max_vov`) を計算する。
*   `max_vov >= 0.5` であれば **PASS (保護)**
*   `max_vov < 0.5` であれば **DROP (除外)**

## 3. 実験結果：FP の除外

追跡対象とした 15件の `fp_divisi_spanning` 候補に対してこのルールを適用しました。

結果として、**15件すべて（100%）が `max_vov < 0.5` となり、DROP 判定（除外）** されました。
これらはすべて段間のギャップを跨ぐように存在しているため、単一の五線領域に対するオーバーラップ率が極めて低く（多くが 0.1〜0.4 台）、狙い通りに安全に除外できることが実証されました。

*可視化結果の例（詳細は `logs/issue120_e2e_recovery/vov_visualizations/fp_examples/` を参照）*
- 例: `[898, 2662, 902, 2810]` (max_vov: 0.23) -> DROP
- 例: `[1002, 3359, 1004, 3641]` (max_vov: 0.37) -> DROP
- 例: `[1852, 1165, 1854, 1621]` (max_vov: 0.44) -> DROP
- 例: `[2305, 1162, 2307, 1618]` (max_vov: 0.44) -> DROP

## 4. 実験結果：GT の保護（マージン検証）

この強力なルール（`max_vov >= 0.5`）が、誤って真の小節線（GT）を落としてしまわないか（False Negative を増やさないか）を確認するため、**データセット全体のすべての GT** に対して同じロジックを適用し、`max_vov` が低い（0.65未満の）「リスクのある GT」を抽出しました。

結果として、**データセット内で最も `max_vov` が低い GT であっても `0.53` であり、閾値の `0.5` を安全に上回っている（全件 100% PASS する）** ことが確認されました。

### Low-VOV GT の要因分類
抽出された `max_vov` が低い GT の例（0.53〜0.64 程度）を分析した結果、その要因は主に以下の 2 つに分類されます。

1. **五線領域の過小評価**: `staff_mask` の抽出段階において、かすれ等により五線領域が実際の五線の幅よりも狭く認識されてしまっているケース。
2. **GTのアノテーション幅が広い**: GT として登録されている線が、divisiの線を含んでしまっているなどの理由で、実際の五線領域よりも上下に長くアノテーションされているケース。

*可視化されたワースト GT の例（詳細は `logs/issue120_e2e_recovery/vov_visualizations/gt_low_vov/` を参照）*
- `Shostakovich-Sym5-Va_page_014_gt_4` (max_vov: 0.53)
- `Shostakovich-Sym5-Va_page_022_gt_52` (max_vov: 0.53)
- `Shostakovich-Sym5-Va_page_022_gt_29` (max_vov: 0.54)
- `Shostakovich-Sym5-Va_page_022_gt_23` (max_vov: 0.56)
- `Sibelius-Violin_Concerto-Viola_page_004_gt_53` (max_vov: 0.57)

これらの「条件が悪い GT」であっても、`max_vov` は `0.5` を超えているため、提案したフィルタによって誤検知（FN）となることはありません。

## 5. 結論

「段間の線は GT ではなく、保護の必要がない」という前提に基づき、**`local_staff_overlap` の `max_vov >= 0.5` というシンプルで単一のルール** を適用することで、ノイズを含む GT を 100% 保護しつつ、`fp_divisi_spanning` を 100% の精度で効果的に一掃できることが証明されました。

既存の `ISSUE120_STAFF_REGION_FILTER_EXPERIMENT_REPORT_JA.md` (Prompt 1 の成果物) の結果を損なうことなく、このフィルタロジックが Divisi 由来の FP に対しても極めて有効であることが確認できました。
