## 1. Project Goal & Current Status
**Goal**: Integrate the trained CNN Classifier (`ResNet18`) into the Hybrid Barline Detection Pipeline to eliminate remaining False Positives.

**Status Update (2026-01-05)**:
- **FN Diagnosis Completed**: The "No Peak" experiment confirmed that previous heuristic filters were suppressing ~65% of valid barlines (Recall increased from 82.6 to 136.7 per page).
- **Candidate Strategy**: The "Ultraloose" strategy is replaced by "No Peak" (Unlimited Candidates + No Peak Check) as the standard for Candidate Generation.
- **Challenge**: This massive recall gain comes with a significant increase in False Positives (~455/page), which the current CNN model (trained on cleaner data) struggles to filter perfectly.

- **Current Config**: "No Peak" Mode
    - `band_source="row_stats"`
    - `scan_x_peak_ratio_min=0.0` (Disabled)
    - `max_per_band=0` (Disabled)
    - `min_ratio=0.50`

## 2. Immediate Tasks (Next Session)

### A. Hard Negative Mining (Priority 1)
**Objective**: Retrain the CNN model using the "Hard Negatives" generated by the "No Peak" strategy.
1.  **Generate Negatives**:
    - Use `expanded_candidates_nopeak.json` as the source for `build_cnn_dataset.py` (via `--fp-source-file`).

2.  **Dataset Augmentation**:
    - Create a new dataset version `cnn_classifier_v3_hardneg`.
    - Mix these new "Hard Negatives" (thick bars, stems, dense text) with the existing dataset.
3.  **Retrain**:
    - Train ResNet18 on this augmented dataset to improve its discrimination boundary.

### B. Post-Processing Filters (Priority 2)
**Objective**: Implement heuristic filters to remove obvious FPs that survive the CNN.
1.  **Stem/Notehead Context**:
    - Use existing notehead detection results. If a candidate is strictly aligned with a notehead, reject it (it's a stem).
2.  **System Consistency**:
    - Check if the candidate aligns vertically with barlines in other staves within the same system.
3.  ** periodicity**:
    - Analyze the spacing of accepted barlines. Reject outliers that break the established periodicity.
