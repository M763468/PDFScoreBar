小節番号付けの経路における音楽的な幾何判定は、解像度に依存しません。距離の閾値は固定のピクセルではなく、五線間隔（`unit_size`）で表します。この契約は Issue #267 で導入されました。その受入記録は本書の末尾に残しています。

## 単位の定義

`unit_size` は、五線と小節線のバウンディングボックスと同じ座標系で測った五線間隔です。

本番の `StaffExtractor` は、連結成分のモルフォロジー処理を行う前の元の五線マスクから、ページ単位の値を1つ推定します。

1. ページ全体の推定では、五線マスクの前景がマスク幅の25%以上を占める行を探します。
2. 隣接するアクティブな行を、線のラン（連続区間）にまとめます。
3. 隣接するランの中心間の間隔を測ります。
4. 間隔の初期中央値を求めます。
5. その中央値の0.5倍から1.5倍の範囲にある間隔だけを残します。
6. それらの平均を使い、対象ページの座標系に変換します。

これは、正規の `barline_staff_units.v1` の作業で確立したのと同じ五線間隔の考え方を使います。保守的なページ全体の推定が得られない場合、`StaffExtractor` は、採用した各成分の元マスクの切り出し範囲内で同じ間隔推定を再試行します。これにより、ページ全体の行持続性の基準を下げずに、抽出できる短い段がモルフォロジー処理後の五線の高さへフォールバックすることを防ぎます。`Staff` は、決定した単位を内部に保持します。番号付けJSONのシリアライザは、この一時的なフィールドを意図的に出力しません。

明示的な単位がない状態で `Staff` を直接または合成で作る場合、番号付けとグループ化のコードは、解像度で正規化した互換用のフォールバックとして `staff_height / 4` を使います。本番の抽出では、通常はマスクから求めた単位を渡すべきです。

## 正規化した音楽的幾何の閾値

| 箇所 | 以前の固定閾値 | 現在の規則 |
| --- | ---: | ---: |
| `MeasureNumberer` の小節線X方向の重複除去 | 15 px | `1.2 * unit_size` |
| `MeasureNumberer` の暗黙の段開始 | 50 px | `4.0 * unit_size` |
| `MeasureNumberer` の最小小節間隔 | 25 px | `1.0 * unit_size` |
| `SystemBuilder` の小節線の揃い判定のX許容値 | 10 px | `0.4 * unit_size` |
| `SystemBuilder` の接続ROIのX余白 | 2 px | `0.08 * unit_size` |
| `SystemBuilder` の五線間の小さな隙間の近道判定 | 5 px | `0.2 * unit_size` |
| `SystemBuilder` の五線の重なりの絶対値フォールバック | 10 px | `0.4 * unit_size` |

SystemBuilder の比率は、受入済みコーパスの規模（五線単位あたり約25 px）付近で、以前の名目上のピクセル挙動を保つように決めています。ページごとの結果に合わせて調整したものではありません。

既存の比率ベースのロジックは比率ベースのままです。これには、divisi/グループ化における五線の高さの比率、コネクタの密度、ゴースト開始の中央値と五線の高さによる判定、実際の五線間の隙間から決める縦方向のモルフォロジーカーネルが含まれます。

## 3段以上の divisi への対応

`ConnectorAwareSystemBuilder` は、生成された左側コネクタの肯定的な根拠が3段以上の五線の連鎖を作る場合、採用済みの小節線候補を持たない声部も段に加えることがあります。新しく加えるつながりは、それぞれ既存の通常の五線の高さに基づく距離制限内に収まる必要があります。生成されたコネクタがない場合は、引き続き連鎖を分割します。より広い救済範囲では、小節線が揃っているという条件を維持します。1段・2段のグループ化は既存の揃い判定の契約を保ちます。これにより、受入済みコーパスで、孤立した空の五線と誤った肯定的コネクタから新しい2段の段が作られることを防ぎます。

3段以上の段では、共有する小節の境界は、1つの五線内で4つの五線間隔にわたるか、2つ以上の異なる五線で揃った候補を持つ必要があります。揃い判定には、既存の `1.2 * unit_size` のX方向の重複除去の許容値を使います。ゴースト境界は引き続きサポートします。これにより、孤立した短い音符や音部記号の断片が、すべての声部を余分な小節に分割することを防ぎます。1段・2段の番号付けは変わりません。

固定した入力の契約と回帰結果は、[実際の楽譜での検証](refactors/issue218_real_divisi_validation.md)を参照してください。

## 五線ではない短いマスク断片

`StaffExtractor` は、採用した各成分を、縦方向の膨張処理の前の元の二値マスクと照合します。成分を棄却するのは、次の条件をすべて満たす場合だけです。

- 横方向に持続する行のランが2つ以下（既存のカバー率0.25の下限による）。
- 前景全体の縦方向の範囲が、五線間隔2つ分より厳密に小さい。
- 元マスクの列ランが、向きが反対の2本の線の軌跡があることを肯定的に示している。具体的には、ちょうど2つのランを持つ列が五線間隔1つ分以上あり、それが横方向に2間隔以上にわたっていること。さらに、上側と下側の中心に最小二乗法で当てはめた直線の傾きの符号が反対で、当てはめた各軌跡がその範囲で0.25間隔以上動いていること。

範囲と間隔はマスク座標で比較します。対象ページへの拡大縮小は判定に影響しません。ページの間隔を優先し、短い五線には既存の成分ごとのフォールバックを使います。間隔が不明な場合は採用のままにします。5本の線が見えることは意図的に要求していません。途切れたり傾いたりしたスキャンの線も使えるようにする必要があるためです。この共通の抽出器は、コネクタの意味情報とMMRの補助幾何も提供します。

1本線の五線や平行な2本線の五線は、傾いたり曲がったり途切れたりしたマスクも含め、採用のままです。行が少なく範囲が短いことだけでは、五線ではない成分の根拠になりません。正当な打楽器譜は線の数を減らした記譜を使うためです。あいまいなスキャンの縁、連桁、不完全なヘアピンのマスクも採用のままです。正当な五線の幾何を落とすよりも、このように明示的に判定を控えることを優先します。最初の2条件だけを使っていた以前の #218 の候補は、この打楽器の契約を満たせませんでした。その56件の空の段の削除と、以前の 43/68 の完全JSON一致の失敗は、過去の結果として残しています。

棄却された成分は `empty_systems` から消えることがあります。その成分は小節にも番号の増分にも寄与しません。番号付きの段から成分が削除される場合は、空の段だけの変化とみなさず、下流での所属・数・番号・幾何の検証が引き続き必要です。

## 元画像の端で切れた開いた区間

グループ化の後、`ClippedSystemEndDetector` は、元画像の幅の位置に論理的な終端境界を1つ追加することがあります。Phase A と Phase C は同じ元画像と規則を使います。このマーカーは五線のグループ化には関与しません。マスクが余白まで伸びているだけでは不十分です。回復には次がすべて必要です。

- 元画像の座標系で、正の五線間隔が分かっていること。
- 最後に割り当てた小節線の後ろに、五線間隔4つ分以上の幅の末尾領域があること。
- 最後の1間隔分の帯と、その手前の4間隔分の帯に、細く規則的な元画像のインクの線ランが5本あること（カバー率 >=0.6、太さ <=0.35 間隔、隣接する間隔 0.75..1.25 間隔、対応する中心のずれ <=0.5 間隔）。
- 2間隔以上の横方向のランを取り除いた後、5本線の範囲内に横方向ではないインクがあること。具体的には、高さ >=0.5 間隔、幅 >=0.4 間隔、面積 >=0.25 平方間隔の成分。元画像のインクの閾値は180です。

空白の末尾、小節線の後ろの短い領域、線の欠落や不確かさ、間隔が不明な場合は、判定を控えます。元画像がない場合や一致しない場合も、既存の挙動を保ちます。5本線の確認は、この任意の切れ端回復のための肯定的な根拠です。五線の成分を採用するときに5本線を要求するものにはなりません。新しい区間は段全体の高さを共有し、物理的な小節を1つ消費します。通常のMMRの上書きは、同じ番号付けの経路で適用されます。

## 意図的に残している固定ピクセルの処理

次の固定ピクセル値は、音楽的な幾何の受入閾値ではなく実装の詳細であり、意図的にピクセルのまま残しています。

- `StaffExtractor.min_height=10` の連結成分のノイズ下限。
- `StaffExtractor` の 20x1 膨張カーネル。
- `StaffExtractor` の 1x50 横方向のクロージングカーネル。
- 暗黙のゴースト線の幅や、空でないROIの保証などの、1ピクセル単位のBBox・インデックスの安全処理。
- コネクタマスク処理におけるモルフォロジーの最小カーネルサイズ。

これらの処理はラスタ処理の仕組みに影響するもので、2本の小節線を同じ小節境界とみなす論理的な距離や、段・小節の構造を推定するための論理的な距離には影響しません。将来、複数のDPIでの根拠により、これらのラスタ処理のいずれかが抽出される五線の構造を変えることが分かった場合は、独自の回帰の根拠を持つ、別のモルフォロジー/セグメンテーションの変更として移行すべきです。

MMR OCR の切り出し・マスクのピクセル幾何は、この契約の対象外です。

## 検証の契約

解像度非依存のテストは、次について 1x/2x の等価な幾何を対象にします。

- 五線単位の推定
- 小節線の重複除去
- 暗黙の開始
- 最小小節幅
- 小節線の揃いによるグループ化の許容値
- 小さな隙間でのコネクタの扱い
- 小節線の五線への重なりによる割り当て

これらの幾何規則を変更する場合は、さらに、同じ保持済みの上流入力で、受入済みの番号付け・物理小節数を変更前のベースラインと比較する必要があります。単体テストだけでは、新しい閾値が受入済みのコーパス全体の数え方の契約を保つことの十分な根拠になりません。
