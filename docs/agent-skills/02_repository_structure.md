# Recommended Repository Structure

This layout allows coding agents to easily discover and use skills.

repo/

    Makefile
    agent.md
    skills/
        repo-tree/
            SKILL.md
            run.sh
        run-tests/
            SKILL.md
            run.sh
        lint-fix/
            SKILL.md
            run.sh

    artifacts/

    docs/
        agent-skills/

Important directories:

skills/ Skill definitions and execution scripts

artifacts/ Files generated by skills

docs/ Documentation that explains skills and workflows to agents

Makefile Provides stable commands for agents

Example agent rule:

Agents should prefer: - Make targets - skill scripts

over generating ad-hoc shell commands.
