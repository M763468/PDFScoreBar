# Long-Horizon Task Workflow — deprecated

This document is no longer a mandatory workflow.

For multi-step work, use the active Issue/PR, current source/tests, and a task-local plan when useful.
Do not create repository-stored task-state files merely because a task has more than three steps.

For evaluation or performance work, the durable requirement that remains is reproducible evidence and
an unchanged evaluation contract; see root `AGENTS.md` and `docs/dev/VALIDATION_POLICY.md`.
