# Staff Band クラスタリングロジックの改善報告

## 1. 背景と課題
Issue #44 の評価プロセスにおいて、幾何学的ルール（五線領域からはみ出している候補を排除するフィルタ）を適用した際、特定のページ（例：`Sibelius-Violin_Concerto-Viola, page_004`）で Recall が大幅に低下（99.9% → 93.7%）する事象が発生した。

調査の結果、正しい小節線が「五線外のノイズ」と誤認され、ルールによって強制的に削除されていることが判明した。

## 2. 原因分析
五線領域（Staff Band）を特定するためのクラスタリングロジック（`cluster_by_y_distance`）に根本的な課題があった。

- **従来のロジック**: クラスタリング閾値を画像高の 5%（`img_h * 0.05`、約 230px）としていた。
- **問題点**: 
    - この値は小節線の高さ（約 110px）の 2倍以上に相当し、段と段を分離するには大きすぎた。
    - 特に **divisi（近接した二段構造）** において、上下の段の間隔（約 230px）が閾値とほぼ同等であったため、二つの独立した段が不適切に一つのクラスタとしてマージされていた。
    - マージされた結果、算出された「中央値（Median）」による五線帯域が一方の段に偏り、もう一方の段にある正しい小節線が「帯域外」と判定された。

## 3. 改善内容
クラスタリングの基準を、画像全体の高さ（`img_h`）から、物理的な構造である **小節線の高さ（`bbox_h`）** に基づく方式へ変更した。

- **新ロジック**: `max_distance = median_bbox_h * 0.5`
- **改善の根拠**: 
    - 同じ段に属する小節線であれば、y方向のズレは五線内に収まる（`bbox_h` 未満）。
    - 閾値を `bbox_h` の半分（約 50px）に絞ることで、異なる段（divisi 含む）を誤ってマージすることを物理的に防止できる。

## 4. 検証結果
### 改善前後の比較 (`Sibelius page 004`)
- **五線認識数**: 10段 → **12段**（divisi の下段が正しく独立した五線として認識された）
- **Recall への影響**: これまで「WILL BE DELETED」とされていた divisi 下段の正解小節線が、すべて「五線内」として保護されることを確認。

### 回帰テスト
他の主要なページ（Shostakovich, Prokofiev 等）においても、五線認識数や精度に悪影響を与えないことを確認済み。

## 5. 結論
本修正により、divisi を含む複雑な楽譜構造においても正確な五線帯域の特定が可能となった。これにより、Recall を損なうことなく、五線外のノイズを排除する幾何学フィルタを安全に運用できる基盤が整った。
