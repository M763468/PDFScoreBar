# Pipeline configuration and entry-point reference

[日本語](CONFIGURATION_REFERENCE.ja.md)

This reference lists how the development pipeline is started and what each key in the
canonical production configuration, `configs/dense_full_pipeline.yaml`, controls. It
describes current source behavior; it does not change defaults or define new settings.
`tests/test_configuration_reference.py`, run by the PR validation workflow, fails when a
canonical key is missing from the key tables of this file or its Japanese translation, is
listed more than once, or has a documented value different from the canonical value. It
does not check the meaning column.

End users of the packaged distribution do not edit this file directly. They use
`docker/distribution.py` as described in the [user guide](../USER_GUIDE.md).

## Entry points

| Entry point | Audience | Notes |
| --- | --- | --- |
| `python3 docker/distribution.py build / preflight / run / review` | Users of the packaged distribution | See the [user guide](../USER_GUIDE.md). |
| `bash scripts/docker_runtime_validation.sh [--config PATH] [--preflight-only] [--service-readiness-smoke] [--pipeline-only]` | Developers | Validates the Docker runtime contract and runs the given config (default `configs/smoke_test.yaml`). Environment: `DOCKER_IMAGE`, `DOCKER_EXTRA_ARGS`, `PDFSCORE_SR_COMPILER_CACHE`, `PDFSCOREBAR_MODEL_CACHE`, `OMR_DLN_MODEL_PATH`. |
| `python -m src.pipeline.main --config PATH [options]` | Developers (inside a prepared environment) | Direct pipeline run; the caller is responsible for mounts and image provenance. |
| `make <target>` | Developers | See the [Makefile surface](../MAKEFILE_SURFACE.md). |

### `src.pipeline.main` options

| Option | Effect |
| --- | --- |
| `--config PATH` | Required YAML configuration. |
| `--run-id ID` | Overrides `run.run_id`. |
| `--output-root PATH` | Overrides `run.output_root`. |
| `--dry-run` | Logs commands without executing them. |
| `--validate-only` | Stops after input resolution and page filtering. |
| `--skip-existing` | Skips steps whose output files already exist. |
| `--page-limit N` | Processes only the first `N` resolved pages. |
| `--debug` | Writes intermediate debug files. |
| `--progress-jsonl PATH` | Writes structured progress events as JSON lines. |
| `--telemetry-summary PATH` | Writes the compact stage/resource summary. |
| `--sample-resources` | Opts in to lightweight process-tree/GPU sampling. |
| `--resource-sample-interval-seconds S` | Sampling interval when sampling is enabled (default `1.0`). |

### Run directory precedence

The run directory is `<output_root>/<run_id>`. `--run-id` takes precedence over
`run.run_id`; if neither is set, a `YYYYMMDD_HHMMSS` timestamp is used. `--output-root`
takes precedence over `run.output_root`, which defaults to `logs/full_pipeline_runs`.
For Issue-scoped work, choose an output root under `logs/issue<N>/` as described in
`AGENTS.md`.

## Canonical configuration keys

Detector, CNN, filter and numbering values in the canonical configuration are accepted
production parameters. Changing any of them, or changing a model, is a new experiment
under the evaluation rules in `AGENTS.md` and the [validation policy](VALIDATION_POLICY.md);
it does not inherit earlier acceptance results.

### `run`

| Key | Canonical value | Meaning |
| --- | --- | --- |
| `run.run_id` | `dense_full_pipeline` | Run directory name; see precedence above. |
| `run.output_root` | `logs/full_pipeline_runs` | Parent directory of run directories. |

| Key | Canonical value | Meaning |
| --- | --- | --- |

| `inputs.pdf_to_images.image_glob` | `page_*.png` | Pattern used to discover page images. |

### `filters`

Page indices in these settings are 1-based.

| Key | Canonical value | Meaning |
| --- | --- | --- |
| `filters.blank_page` | `auto` | `auto` measures each page; a boolean forces the result for all pages; a list marks the listed pages. |
| `filters.blank_page_config.pixel_threshold` | `245` | Blank-page measurement parameter. |
| `filters.blank_page_config.max_ink_ratio` | `0.003` | Blank-page measurement parameter. |
| `filters.blank_page_config.max_stddev` | `12.0` | Blank-page measurement parameter. |
| `filters.staff_detect` | `auto` | Same value forms as `blank_page`, for staff-detection failure. |
| `filters.staff_detect_config.min_nonzero_ratio` | `0.001` | Staff-detection measurement parameter. |
| `filters.user_exclude` | `[]` | Pages excluded by the user. |
