## Grouping and semantic interpretation

`numbering_final.pages[].systems[].staves[]` contains staff-mask connected components.
Its length is not a musical staff or divisi count. No maximum-two grouping rule is
introduced.

A same-x barline on another component is also not grouping evidence. Semantic
redundancy must be established from both:

1. the actual final system membership; and
2. positive connector evidence linking the target component into that system.

The comparison runner now:

- distinguishes the SR/CNN image from the original numbering image;
- validates their scale and coordinate contract;

The earlier `96 -> 111` grouped comparison was produced before these runner corrections.
It remains valid evidence that side-context expansion is broad, but it is not accepted
as proof of the target's musical semantic role.
