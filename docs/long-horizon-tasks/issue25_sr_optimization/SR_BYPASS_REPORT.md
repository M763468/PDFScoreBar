# SR Bypass & Scale Evaluation Report: Issue #25 (Final Resolution)

## 1. 概要
SR（超解像）のスケール別精度およびバイパス時の影響を、全68ページの評価データセットを用いて厳密に検証した。
検証の結果、SR x2 が精度・速度・リソース消費のすべての面で最も優れたバランスを持ち、SR x4 と同等の究極の精度（Recall 100%）を達成できることが実証された。

## 2. 定量的結果 (Global 68 Pages) - 最終検証

| 構成 | 全体 Recall | TP / **FN** | 平均処理時間 (1枚) | VRAM | 評価 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **SR x2** | **100.00%** | **3581 / 0** | **約5.2秒** | 中 | **正式推奨・デフォルト** |
| **Bypass** | 99.97% | 3580 / 1 | **約2.1秒** | 最小 | 高速・準最高精度 |
| **SR x4** | 100.00% | 3581 / 0 | 約15秒以上 | 特大 | 過剰性能 |

## 3. 技術的ブレークスルー：CNN Downscaling
SR モードにおいて以前発生していた精度低下は、CNN 分類器の学習解像度（300DPI相当）と入力画像の解像度不一致が原因であった。
本改修により導入された **「CNN Downscaling 修正」** は、以下のプロセスを可能にした。
1.  **Probe Scan (SR空間)**: 高解像度画像上でプローブ探索を行い、密集した二重線などを物理的に分離して候補を抽出。
2.  **CNN Scoring (標準空間)**: 抽出した候補を判定する直前に、画像を 300DPI 相当（INTER_AREA）に縮小。CNN にとって最適な画像特徴量で判定。
これにより、SR による「線の分離能力」と CNN の「高精度な判定」の両立に成功した。

## 4. 運用指針
- **基本設定**: **SR x2** (`enable_sr: true`, `sr_scale: 2`) を基本運用とする。
- **高速設定**: 大量の譜面を極めて短時間で処理する必要がある場合のみ **Bypass** を使用する。
- **SR x4**: 基本的に SR x2 で網羅性が確保されるため、通常使用は非推奨とする。
