# SR Bypass & Scale Evaluation Report: Issue #25 (Final Resolution)

## 1. 概要
SR（超解像）のスケール別精度およびバイパス時の影響を、全68ページの評価データセットを用いて厳密に検証した。
調査の過程で、SR モードにおいて CNN スコアが著しく低下する問題を特定し、パイプラインの修正により解決した。

## 2. 定量的結果 (Global 68 Pages) - 修正後

| 構成 | 全体 Recall | TP / **FN** | 処理時間 (1枚) | VRAM | 備考 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **SR x4** | **100.0%** | 3580 / **1** | ~15秒以上 | 特大 | 最高精度・極薄線救済 |
| **SR x2** | **100.0%** | 3580 / **1** | ~5〜8秒 | 中 | **x4と同等の最高精度** |
| **Bypass** | **99.6%** | 3566 / **15** | **~1.5秒** | 最小 | 高速・高精度 |

*(※ 修正前、SR x2 は Recall 94.5% まで低下していたが、現在は解消済み。)*

## 3. 分析：特定された問題と解決策
- **問題（CNN解像度不一致）**: CNN 分類器が 300DPI 特徴で学習されているため、SR 画像（高解像度・高鋭度）を直接入力すると、本物の線をノイズと誤認しスコアが 1.0 -> 0.01 程度まで急落する現象が発生。
- **解決策（CNN Downscaling）**: 
    - **Probe Scan**: SR 画像上で実行。高い分離能力を維持し、密集した二重線を正確に抽出。
    - **CNN Scoring**: クロップ・判定前に画像を **300DPI 相当（INTER_AREA）に縮小**。これにより、SR による構造補完の恩恵を受けつつ、CNN にとって最適な特徴量での判定が可能となった。
- **座標系の一貫性**: パイプライン全体で座標を適切にスケーリングするよう修正し、SR 空間での検出と標準空間での判定をシームレスに結合。

## 4. 最終結論
- **デフォルト構成**: 引き続き **Bypass (SRなし)** を推奨。99.6% の精度は実用上十分であり、処理速度のメリットが極めて大きい。
- **最高精度モード**: 完璧な結果が必要な場合は **SR x2** を推奨。SR x4 と同等の精度を、より短い時間と少ない VRAM で達成可能。
- **SR x4 に関する方針**: 特殊なケースを除き、SR x2 で十分な精度が得られるため、リソース消費の激しい x4 は予備的なオプションとする。
