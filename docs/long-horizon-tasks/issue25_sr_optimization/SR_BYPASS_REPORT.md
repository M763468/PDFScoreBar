# SR Bypass & Scale Evaluation Report: Issue #25 (Final Verification)

## 1. 概要
SR（超解像）のスケール別精度およびバイパス時の影響を、全68ページの評価データセットを用いて厳密に検証した。
PR #76 で確立された「Golden Config」に基づき、過去に最高精度（FN=1）を達成した際の候補位置（Bands）を固定した状態で、画像ソース（Bypass, SR x2, SR x4）を差し替えて比較を行った。

## 2. 定量的結果 (Global 68 Pages)

| 構成 | 全体 Recall | TP / **FN** | 処理時間 (1枚) | VRAM | 備考 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **SR x4** | **100.0%** | 3580 / **1** | ~15秒以上 | 特大 | 最高精度 |
| **SR x2** | **94.5%** | 3385 / **196** | ~5〜8秒 | 中 | **大幅な精度低下** |
| **Bypass** | **99.6%** | 3566 / **15** | **~1.5秒** | 最小 | 高速・高精度 |

## 3. 分析：スケール別の特性
- **SR x4**: 依然として最高精度。極薄の線を「構造補完（Structural Repair）」することで CNN の判定スコアを安定させ、FN=1 まで救済可能。
- **Bypass (SRなし)**: 重心補正（Golden Config）の効果により、SRなしでも 99.6% の高精度を維持。速度面で圧倒的に有利。
- **SR x2**: 期待に反して Bypass よりも大幅に精度が悪化。座標のズレではなく、CNN スコアそのものが閾値を下回る（0.9 -> 0.01 への低下など）現象が多発している。

## 4. 結論
- **デフォルト構成**: 速度と精度のバランスから **Bypass (SRなし)** を推奨。
- **最高精度モード**: 完璧な網羅性が必要な場合のみ **SR x4** を使用。
- **SR x2 に関する方針**: 現状の CNN 分類器との相性が極めて悪いため、追加学習なしでの採用は見送る。

---
## 5. 追加調査課題
SR x2 において、なぜ Bypass よりも CNN スコアが著しく低下するのか、具体的な画像特徴レベルでの原因調査を継続する。
