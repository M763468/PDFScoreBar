# Issue #410: 手動受入の指摘と修正

## 利用者の確認結果

2026-10-15の利用者報告では、Festival OvertureとSibeliusの休符修正・保存・PDF生成を
数分で完了し、使い勝手は大きな問題なし。楽章境界は未設定だった。
これは当該2曲の操作受入の証拠であり、Full68の絶対番号や全小節線の正しさの認証ではない。
番号規約は、Festivalは楽章分割なしで曲内通し、Sibeliusは各楽章を1から開始とする。

## 指摘への対応

| 指摘 | 変更 |
| --- | --- |
| 右上の前後移動を使わなかった | ボタンを削除。左のページ一覧と左右キーで移動 |
| 保存対象が不明、右下で見つけにくい | 上部に「このページを保存」とPDF生成を配置。ページ移動時の自動保存、PDFには全ページの保存済み変更を反映することを明記 |
| 「詳細と根拠」の必要性が不明 | 「操作のヒント」に整理し、内部identityの表示を除去。操作に必要な説明は選択中の修正種別の直下へ |
| 「このページの修正」の意味が不明 | MMRでは「このページの小節一覧」、他の操作では記録した修正または境界の一覧と表示 |
| 画面下部でクリックがずれる | 親全体の高さをbitmapへ代入していた不具合を修正。canvas専用領域、両軸の表示倍率を使う入力座標変換、表示領域のサイズ監視を追加 |
| ズーム後に移動しにくい | 「ページを移動」で左ドラッグ、「ページ全体を表示」で戻す操作を追加。領域外へドラッグしても終了できる |
| 楽章境界を追加できない | 検出候補なしでも手動追加を有効化。選択段の前で1へ戻す境界を即時保存し、PDFへ適用 |
| 小節・小節線と削除の区別が不明 | 「小節を追加」を「この区間を小節として数える」に変更。小節線は区切りの分割・結合、修正の取り消しは記録した操作の解除と説明 |

手動の楽章境界では検出evidenceを捏造せず、実際の保存reviewのSHA-256を解決済み入力へ保持する。
保存中断やreview改変で解決済み入力と一致しなくなった場合は適用を拒否する。
候補付きの既存review/finalize経路と、候補なしを否定判断にしない規約は維持する。

## 検証範囲と証拠

保持rootは `logs/issue410/ux-feedback/20261015/`。利用者が保存した元の修正・PDFは14ファイルの
SHA-256を先に記録し、別コピーで検証後も全件一致した。

修正前の固定candidate `fedf8608ee5b095f175ac45931433069b688f20a` と修正後の画面を
実Chromiumで比較した。1440×1000、1000×800、800×900で、上部と最下段の小節中央をクリック。
修正前は最下段で1〜2段上が選択された。修正後は全6箇所が一致し、拡大後の選択と
120×60のドラッグ移動も一致した。`browser-check.cjs` と `browser-report.json` に記録する。

実GUIでSibeliusのII（6ページ先頭段）とIII（7ページ先頭段）を手動境界として追加し、
保存からPDF取得まで確認した。`verify-numbering.py` は保持MMRの固定加算と利用者の4小節補正、
明示した2境界から全613物理小節の期待番号を検証し、全10ページの実PDFの画像pixelsを照合した。
II・IIIの先頭は実PDFでも1。上流推論・MMR再認識は実行していない。

この検証は保持された幾何とMMRに対する修正伝播の検証であり、未修正の小節線残差を含めて
絶対番号が全て正しいという判定ではない。#416の下流disposition、Festival旧sampleのGT修正、
Sym5 IIIの規約と実譜面での適用確認、最終accepted developからのfreezeは引き続き別gateとする。

元の候補・評価記録は [VALIDATION_20261015.md](VALIDATION_20261015.md) に保持する。
今回の変更後の候補は識別子を新しくし、変更したGUI・手動境界経路を再検証する。

## 追記: 修正版の受入と右側表示の整理

上記rc2に対し、利用者から「右側の表示がちょっとごちゃごちゃしているが、それ以外は良い」
との確認を取得した。先の「未取得」はrc2検証時点の記録であり、この報告で更新する。
右側表示には以下の追加整理を行った。

- 対象・入力・追加ボタンを先に置き、休符の確認ボタンをその後へ配置。
- 操作説明は短い案内を常時表示し、長い手順は「操作のヒント」へ折りたたむ。
  休符の見逃し・誤読の説明は参照でき、「警告がなくても原譜の休符数字を確認」は常時表示。
- 修正状況は未保存・記録済み・エラーの件数とPDFの状態を表示し、種別ごとの内訳は
  「保存状況の詳細」へ折りたたむ。保存エラーは内訳を閉じていても常時表示する。
- 手動楽章境界では重複する対象表示と、選択肢が1つしかない操作欄を非表示にする。
  候補付きの境界確認では境界／境界なしの選択肢を引き続き表示する。

変更はHTML/CSS、ブラウザー側の表示処理、英日copyのみ。保存・適用・番号付けの契約は変更しない。
この追加整理に対する利用者確認はまだ取得していない。
