# PDFScoreBar Windows版 — 限定試用ガイド

この文書は Issue #508 の限定試用に用いる暫定版です。試用で得たフィードバックに応じて更新します。
開発者向けのビルド手順は [Windows portable README（GitHub、英語）](https://github.com/M763468/PDFScoreBar/blob/develop/tools/windows_portable/README.md) を参照してください。Linux/Docker版は [別のユーザーガイド（GitHub）](https://github.com/M763468/PDFScoreBar/blob/develop/docs/USER_GUIDE.ja.md) を使用します。

## 1. 動作環境

- Windows 10/11（64bit）
- NVIDIA GPU（VRAM 6 GB以上）と対応ドライバー
- 配置先ドライブの空き容量20 GB以上
- 初回セットアップ時のインターネット接続（PyPI）

Docker、WSL、システムPython、CUDA Toolkit、コンパイラーを別途インストールする必要はありません。
今回の版はWindows 11・RTX 4060で検証されています。その他の環境は試用時に確認します。

## 2. ファイルの準備と試用条件

配布された `PDFScoreBar` フォルダーを、例えば `C:\PDFScoreBar` に配置します。
**フォルダーの場所は短い英数字だけのパス（40文字以内）**にしてください。日本語のフォルダー名や深い配置先は避けます。
処理対象のPDFのファイル名・入力パスには日本語も使用できます。

受け取った `PDFScoreBar-compliance/supplemental/nvidia-cuda-redistributable/RECIPIENT_TERMS.md` とライセンス・注意事項を確認し、試用条件への同意を管理者に伝えてください。
配布物のハッシュ確認用に `PDFScoreBar.build_manifest.sha256` も渡されます。
`PDFScoreBar` フォルダーと `PDFScoreBar-compliance` は別のフォルダーのまま保管してください。

## 3. 初回セットアップ

Windowsの「コマンド プロンプト」を開いて、次の順序で実行します。

```bat
C:\PDFScoreBar\PDFScoreBar.cmd setup
C:\PDFScoreBar\PDFScoreBar.cmd preflight
```

`setup` では必要な `triton-windows` をPyPIから利用者自身が取得します。取得元と条件が表示されるので、確認して同意する場合に `y` を入力してください。初回はGPUコンパイルの確認も行います。

`preflight` はGPU・CUDA・必要なファイルを検査します。失敗した場合は、表示されたエラーを記録して試用管理者に報告してください。
正常に完了した `setup` は次回から不要です。通常の実行にネット接続は必要ありません。

## 4. PDF楽譜を処理する

次のコマンドでアプリを起動します。

```bat
C:\PDFScoreBar\PDFScoreBar.cmd serve
```

ブラウザーが自動で開かない場合は `http://127.0.0.1:8010/` を開きます。
アプリはこのコンピューター内のローカル接続を使用します。

1. 処理したい楽譜PDFを選び、必要なら対象ページを指定します。
2. 「番号付けを開始」を押し、ジョブの完了を待ちます。
3. 出力された番号付きPDFを開いて確認します。
4. 必要に応じて「補正GUIを開く」で修正し、保存後に修正済みPDFを生成します。

処理時間はPDFの内容やページ数、GPUを使用する他のアプリによって変わります。

## 5. 結果を確認・修正する

**自動番号付けは確認が必要な下書き**です。成功表示だけで番号がすべて正しいと判断しないでください。

特に、小節線の位置、各段の開始番号、楽章の区切り、**複数小節休符に印刷された小節数**を確認します。
複数小節休符の見落としは通常の1小節として表示されることがあるため、警告のない場所も含めて確認してください。

誤りがあれば補正GUIで対象を選択して修正を追加し、ページの変更を保存してから修正済みPDFを生成します。
修正した場所だけでなく、後続の小節番号も確認してください。
詳しい複数小節休符の確認方法は [日本語ユーザーガイド（GitHub）](https://github.com/M763468/PDFScoreBar/blob/develop/docs/USER_GUIDE.ja.md#複数小節休符を確認して修正する) にあります（操作内容は共通ですが、起動手順はこのWindows版ガイドに従ってください）。

## 6. 終了・再開

終了するときは、起動したコマンドプロンプトで `Ctrl+C` を押します。
再開時に `PDFScoreBar.cmd serve` を起動すると、保存済みのジョブを再び開けます。

入力PDF、生成したPDF、補正履歴は `PDFScoreBar\jobs` 以下に保持されます。
**補正・評価が完了するまでは `jobs` を削除しないでください。**
フォルダーを移動する場合はアプリを停止し、保存済みジョブごとまとめて移動してください。

## 7. 試用結果の報告

管理者へ、初回 `setup` / `preflight` の成否、PCのGPUとVRAM、対象ページ数、所要時間、番号の誤り、手動補正の量、操作で迷った点、不具合を伝えてください。

楽譜PDF・出力PDF・ジョブ内のデータには個人・組織の資料が含まれる可能性があります。**公開GitHub Issueにはアップロードしないでください。**
サンプルが必要な場合は管理者が指定した非公開の方法で共有してください。

## 8. 困ったとき

- `setup` が失敗する：ネットワーク接続、空き容量、表示されたエラーを確認します。途中で中断した場合は通常の `setup` を再実行できます。
- `preflight` が失敗する：GPU、ドライバー、配置先パス、空き容量を確認してエラーを管理者に伝えます。
- ブラウザーが開かない：コマンドプロンプトの `serve` が動いているか、`http://127.0.0.1:8010/` を確認します。
- 小節番号が間違っている：補正GUIを使用します。修正できない場合は、問題のページと位置を記録して管理者へ報告します。

試用中に見つかった不具合や改善要望は、管理者が [Issue #508](https://github.com/M763468/PDFScoreBar/issues/508) から追跡します。
