Help: reviewing corrections

Overlay controls are above the score canvas. Labels start off to keep the score readable.

  • Barlines only: Measures off, Barlines on, Labels off, Base MMR state off, Manual state off.
  • Measures only: Measures on, Barlines off, Labels off, Base MMR state off, Manual state off.
  • Staged removals: keep Manual state on; staged barline removals remain visible even if Barlines is off.

Selected objects and active drafts always stay visible. This lets you hide other layers without losing the active target.

Other correction types: choose Type/Operation → Select object or Draw barline box → Stage change → inspect Current page results → Save corrections.

Movement boundaries: a boundary is always placed before the selected system, never after it. Click anywhere inside the intended system; the whole system becomes the movement target. If a measure is hit, its measure number is shown only as selection context. Yellow marks a suggested boundary, purple a confirmed boundary, cyan a boundary already used by the current numbering, and gray a checked no-boundary location. Choosing the boundary/no-boundary action saves that decision immediately. Finish movement review only creates the boundary data for a later numbering run; it does not alter the currently displayed score.

Visible Page / System / Measure identifiers are 1-based. Saved correction indices keep the existing internal 0-based schema.

Canvas: mouse wheel = zoom; Space+drag or middle mouse = pan. Left/Right arrows change page. Delete/Backspace unstages the selected correction when applicable.

Save writes package-local correction JSON under review/corrections/; applying corrections and regenerating outputs is a separate step.

Current page results
MMR rows show base from the configured MMR artifact and effective after manual corrections. Movement rows show suggested boundaries, confirmed boundaries, checked no-boundary locations, and boundaries already used by the current numbering. Every movement location is expressed as before System N. Visible Page / System / Measure identifiers are 1-based; saved correction indices remain unchanged.
