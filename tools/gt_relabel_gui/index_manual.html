Help: reviewing corrections

Overlay controls are above the score canvas. Labels start off to keep the score readable.

  • Barlines only: Measures off, Barlines on, Labels off, Base MMR state off, Manual state off.
  • Measures only: Measures on, Barlines off, Labels off, Base MMR state off, Manual state off.
  • Staged removals: keep Manual state on; staged barline removals remain visible even if Barlines is off.

Selected objects and active drafts always stay visible. This lets you hide other layers without losing the active target.

Correction flow: choose Type/Operation → Select object or Draw barline box → Stage change → inspect Current page results → Save corrections. Save corrections writes every staged correction type on the current page.

Visible Page / System / Measure identifiers are 1-based. Saved correction indices keep the existing internal 0-based schema.

Canvas: mouse wheel = zoom; Space+drag or middle mouse = pan. Left/Right arrows change page. Delete/Backspace unstages the selected correction when applicable.

Save writes package-local correction JSON under review/corrections/; applying corrections and regenerating outputs is a separate step.
